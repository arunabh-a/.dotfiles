# dotfiles - updated for mac 

## Installation

```bash
git clone
cd dotfiles

```

### Being Inside .dotfiles folder

- `.zshrc` : the zsh shell config (aliases and exports)
- `.zshenv` : the zsh environment variables
- `.p10k.zsh` : Powerlevel10k config (needs Oh my Zsh)
- `.gitconfig` : Git config for global github access
- `.config/` : Configs of some apps on mac (neovim, raycast)
- `.oh-my-zsh/` : Oh my Zsh Config for ZSH shell (plugins)
- `.ssh/config` : The Configs to my Servers and VMs
